# > portfolio escolar

## // descrição
este repositório contém meu portfólio escolar com as atividades realizadas no terceiro ano do ensino médio com curso técnico integrado no SESI-SENAI, separadas por matéria e trimestre.

## > conteúdo
- página para cada matéria do ensino médio (humanas, linguagens, matemática e natureza)
- página para cada matéria do curso técnico (desenvolvimento de sistemas, modelagem de sistemas, banco de dados e IoT)
- fotos do ensino médio
- certificados
- sobre mim com breve resumo de quem sou, em conjunto com links importantes
- links para os portfólios anteriores e para meu curriculum vitae realizado em 2024

## > tecnologias utilizadas
- html5, css3 e js
- markdown (para esse readme :p)

## // como navegar
- todas as páginas de área estão na navbar na parte superior do site
- dentro de cada página de área, existem três abas; uma para cada trimestre
- dentro dessas abas estão os cards de atividade
- os cards contém imagem, descrição e habilidades, a atividade pode ser acessada na íntegra ao clicar neles
